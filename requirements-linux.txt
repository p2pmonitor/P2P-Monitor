#   python3, python3-tk, python3-pip, xdotool, x11-utils, imagemagick
#
# discord.py is intentionally NOT listed here. It's only needed for the
# Discord bot/Gateway features (vs. plain webhook notifications, which use
# stdlib urllib and need nothing extra), so it's installed on demand the
# first time "Run Bot Setup" is used (see ui/settings_tab.py) rather than
# required for every install.
